Christian Reaves

Program Description:

This program demonstrates object-oriented programming by creating a class called Record. The Record class represents a music record and contains three attributes: title, artist, and year.

The program also contains two methods:

1. display_info()
This method displays the title of the record, the artist, and the year the record was released.

2. record_age()
This method calculates how old the record is by subtracting the release year from the current year.

The main program creates a Record object using the Record class and calls both methods to display information about the record.

Files:

objects_reaves.py - Contains the Record class, attributes, and methods.

main_reaves.py - Creates a Record object and calls the methods from the Record class.

Example Record:

Title: Gemini Rights
Artist: Steve Lacy
Year: 2022

The program will display the record information and calculate the age of the record.
